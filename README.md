# Гараж — Telegram-бот для автовладельца

Личный ассистент, который следит за техническим состоянием машины: напоминает о замене масла, фильтров и жидкостей, ведёт журнал ремонтов и считает расходы.

## Зачем это нужно

Большинство водителей забывают, когда в последний раз меняли масло, тормозную жидкость или ремень ГРМ. В итоге — либо меняют слишком рано (переплата), либо слишком поздно (риск поломки). Бот решает эту проблему: он сам знает интервалы, сам напоминает, сам ведёт историю.

## ✨ Что умеет бот

### Учёт и напоминания
- Регистрация машины: марка, модель, год, VIN, пробег, среднемесячный пробег.
- 8 типов обслуживания с автонапоминаниями: масло, воздушный фильтр, салонный фильтр, тормозная жидкость, охлаждающая жидкость, свечи, общее ТО, ГРМ.
- Справки перед каждым вопросом — бот объясняет, почему такие интервалы и от чего они зависят. Пользователь принимает решение сам.
- Планировщик проверяет каждое утро, у кого пора менять, и присылает напоминания. Не спамит: «скоро менять» — один раз, «просрочено» — раз в 7 дней.
- Кнопки под напоминанием: «✅ Уже поменял», «⏰ Напомнить позже», «❌ Пропустить на месяц».
- Snooze: можно отложить напоминание без изменения данных.

### Журнал ремонтов
- Любые работы: замена амортизаторов, ремонт рулевой рейки, замена стекла — что угодно.
- Автокатегоризация по названию: подвеска, тормоза, двигатель, трансмиссия, электрика, кузов, прочее.
- Ручное изменение категории, если бот ошибся.
- Фильтр истории: всё вместе / только замены / только ремонты.

### Расходы и экспорт
- Разбивка расходов: по видам (замены vs ремонты) и по категориям.
- Экспорт всей истории в CSV — с колонками «Категория», «Название», «Запчасти», «Работы».

### Многопользовательность
- Один пользователь может вести несколько машин.
- У каждой машины — своя история, свой пробег, свои интервалы.

## 🚀 Как запустить локально

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ваш-логин/my_garage_bot.git
cd my_garage_bot

### 2. Создать виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate   # для macOS / Linux
# venv\Scripts\activate    # для Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Получить токен бота

- Откройте Telegram → `@BotFather` → `/newbot`.
- Следуйте инструкциям, скопируйте токен.

### 5. Создать `.env`

```bash
cp .env.example .env
```

Откройте `.env` и вставьте свой токен:

```
BOT_TOKEN=7123456789:AAH_ваш_токен_здесь
```

### 6. Запустить

```bash
python bot.py
```

В терминале появится `Бот запущен. Планировщик активен.` — откройте бота в Telegram и нажмите `/start`.
